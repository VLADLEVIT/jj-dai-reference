#06KIND: COMPOSITION STATUSprev: #05

The honest sentence

what changed · what must not be overclaimed

v0.4.1 closed the identity gap. v0.5-dev5 closed the cryptographic boundary. v0.5-dev6 made replication sound. v0.5.1 closes P1: weights are attested and boot-gated, verification runs through diversity-constrained panels with the generator's provenance passed explicitly, roots anchor beyond the trust domain, and every network path can run mTLS.

Still true, and said plainly: without TEE, attestation proves the operator's measurement — not what the engine loaded into memory; OTS custody is not local Bitcoin verification; attribution assumes an honest, anchored issuer chain; recovery restores only what was replicated, never the local-only commitment salts. A reference node is not a production peer.
